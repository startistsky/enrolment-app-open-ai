# Enrolment App Open AI

ASD 2026 Agentic AI semester project.

## Project Overview

This project is an integrated Agentic AI university management application developed using Python, Flask, HTMX, SQLite, Docker, Ollama and GitHub Actions.

## Team Features

- Student 1: Course Management
- Student 2: Assignment Management
- Student 3: Study Plan Management
- Student 4: Campus Event Management
- Student 5: Career and Internship Management
